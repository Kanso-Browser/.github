# Kanso

**Minimalist software built with focus, privacy, and low overhead.**

We build lightweight desktop tools designed to stay out of the way. Instead of bundling heavy runtimes or routing user data through unnecessary proxies, we rely on native OS capabilities, modern Rust backends, and clean, responsive interfaces.

---

### Core Principles

* **Privacy by default:** Zero hidden telemetry, direct origin requests, and opt-in external services.
* **Low overhead:** Native system webviews and compiled backends over bloated memory footprints.
* **Directness:** Fast, keyboard-friendly workflows without visual clutter.

---

### Featured Project

#### [Kanso Browser](https://github.com)
A minimalist desktop web browser for Windows focused on privacy, directness, and speed.
* **Architecture:** Splits UI chrome and page rendering across native Windows WebView2 instances coordinated by a Rust backend.
* **Tech Stack:** `Rust` · `Tauri v2` · `React.js` · `TypeScript` · `Zustand` · `Astro.js`
